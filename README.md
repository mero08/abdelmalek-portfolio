# Abdelmalek Marwan — Portfolio

Static bilingual portfolio site (React + Vite).

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The app uses client-side routing (`BrowserRouter`). For static hosts, all routes must fall back to `index.html`. On Vercel this is configured in `vercel.json`.
